## 1. 项目概述与产品定位

### 1.1 一句话定位
一个让信息学/编程竞赛选手**在浏览器里刷笔试题、按分类练习、做限时模拟考、即时看判分与解析、沉淀错题、查看学习统计**的轻量训练网站，题库覆盖**所有信息学竞赛的笔试题目**——包括但不限于蓝桥杯、CSP-J/S、NOIP、NOI 笔试、各省/市/校级比赛、ACM/ICPC 相关笔试及其他编程竞赛笔试。

### 1.2 与 OJ 平台的本质区别

| 维度 | OJ 平台 | 本项目 |
| --- | --- | --- |
| 题目形态 | 编程题（写代码→评测） | **选择题 / 判断题 / 多选题 / 阅读程序题**（笔试题） |
| 判分方式 | 编译运行比对输出 | **答案比对**（单选唯一、多选全对得分、判断二选一） |
| 核心场景 | 编程能力训练 | **知识记忆、理解辨析、考试熟练度**训练 |
| 考试规则 | 实时提交 | 模拟考限时、交卷后统一出成绩 |

### 1.3 目标赛事背景（题库内容设计依据）
题库覆盖**所有信息学竞赛的笔试题目**，MVP 预置以下竞赛类型（均为通用字段，后续可任意扩展）：

- **蓝桥杯**（青少组/大学组等笔试环节的真题与模拟题）。
- **CSP-J/S 第一轮（初赛）**：笔试形式，题型含单项选择、判断题、阅读程序（选择/判断）等 —— 最大量用户群之一。
- **NOIP 初赛笔试**：历届初赛以笔试题形式存在，真题与知识点是日常训练的常用素材。
- **NOI 相关笔试**（NOI 笔试等，选手须通过的笔试题）。
- **各省/市/校级比赛**：各地信息学奥赛选拔赛、校内编程竞赛的笔试题（区域性赛事）。
- **ACM/ICPC 相关笔试**：以机试为主，但相关选拔/笔试环节的笔试题亦可收录。
- **其他/综合**：其他各类编程竞赛笔试、综合练习题库。

> 设计原则：**竞赛类型为通用可扩展字段**，同题目可打多个竞赛类型标签；新增一种竞赛类型只增数据、不改代码、不改页面结构（筛选选项由数据配置动态生成）。

### 1.4 产品原则（贯穿全站）
1. **即时反馈**：练习模式做完即判、即看解析，强化记忆。
2. **低门槛**：注册即用，浏览器打开即刷题，无需配置环境。
3. **数据驱动**：错题自动沉淀，统计反映薄弱分类，引导学生针对性复习。
4. **考试真实感**：模拟考有限时、自动交卷、考后统一出成绩，还原考场节奏。
5. **全竞赛通用**：题库/知识点/题型设计对任何竞赛笔试题通用，分类维度与竞赛类型解耦。

## 2. 目标用户

### 2.1 主用户：参加各类信息学/编程竞赛笔试的选手（90%）
- **Persona A ——「初赛冲刺生」（主力）**
  - 中小学生为主，备赛 CSP-J/CSP-S、NOIP 初赛、蓝桥杯青少组、省市校级比赛等；每天可支配训练 0.5~2 小时。
  - 痛点：笔试知识点杂（语言、数据结构、算法、数学、计算机基础），不知道薄弱点；纸质真题做完就丢，错题无法沉淀。
  - 目标：考前 1~3 个月高强度刷题 + 模拟考，快速提升正确率。
- **Persona B ——「长期训练生」**
  - 系统学习信息学 1 年以上（中学生/大学生），日常刷题保持手感，备考 CSP-S 第一轮、NOI 笔试、蓝桥杯等。
  - 痛点：需要按分类/难度/知识点精细化训练，希望看到长期进度曲线。
  - 目标：分类突破 + 模拟考验证水平。
- **Persona C ——「考前突击生」**
  - 临近某场比赛 1~2 周才开始刷题，时间紧（含临时转战其他赛事的情况）。
  - 痛点：没时间系统学，只想做**真题模拟卷 + 看解析**。
  - 目标：模拟考试 + 错题重练，用最短时间过高频考点。
- **Persona D ——「多赛事选手」**（新增，因题库扩展）
  - 同时参加多项比赛（如蓝桥杯 + CSP-J + 校内赛），需要按竞赛类型分别备考。
  - 痛点：不同赛事题型/难度/风格不同，混在一起刷效率低。
  - 目标：按竞赛类型筛选刷题、各赛事分别模拟考。

### 2.2 次要用户：信息学老师/教练（10%，MVP 不针对）
- 希望布置任务、查看学生进度 —— **MVP 不做班级/布置功能**，留待后续版本。

### 2.3 使用场景
- 碎片时间（课间/午休/晚自习）：练习模式刷 10~20 题。
- 整块时间（周末）：做一套限时模拟卷。
- 赛前一天：只看错题本 + 重练错题。
- 切换赛事备考：在题库按竞赛类型切换（如蓝桥杯 ↔ CSP-J）。

### 2.4 用户核心诉求（按优先级）
1. 有足够多、足够准的笔试题可刷，且覆盖自己参加的赛事（P0：种子题库 + 分类完整 + 竞赛类型可扩展）。
2. 做完立刻知道对错和为什么错（P0：即时判分 + 解析）。
3. 知道哪里弱（P0：分类统计 + 错题本）。
4. 考前能模拟真实考试（P0：模拟考 + 限时 + 自动交卷）。
5. 进度跨设备不丢（P0：账号系统 + 服务端存储）。

## 3. 功能范围与优先级

> 优先级标注：**P0 = MVP 必做**；**P1 = 建议做（资源允许进首版，否则二期）**；P2 = 后续版本。

### F0 用户系统（P0，支撑性功能）
- F0.1 注册（用户名 + 密码 + 确认密码；用户名唯一）。
- F0.2 登录 / 退出（JWT 鉴权，登录态持久化）。
- F0.3 个人中心（MVP 极简：展示用户名；头像/昵称修改 P1）。
- F0.4 登录保护策略：未登录可浏览题库列表与题目，但**练习答题、模拟考、错题本、统计需登录**（降低首访门槛，P0 决策）。

### F1 题库浏览与分类（P0）
- F1.1 **竞赛类型筛选**（P0，通用可扩展）：MVP 预置 **蓝桥杯 / CSP-J / CSP-S / NOIP / 省市校级 / 其他·综合**（可多选或全部）；竞赛类型由**数据配置驱动**，新增竞赛类型（如 ACM/ICPC 相关笔试、NOI 笔试等）只需添加配置数据，**无需改代码**。同题目可属于多个竞赛类型。
- F1.2 **知识点分类**（P0，固定 8 类，数据可扩展；**对所有竞赛通用**）：
  1. C++ 语法基础（语法、类型、运算符、输入输出、作用域、STL 基础）
  2. 数据结构（数组、链表、栈、队列、树、图、哈希、堆）
  3. 算法（排序、二分、递归、贪心、DP、搜索、图论、字符串）
  4. 数学（数论、组合数学、概率、逻辑）
  5. 数制与编码（进制转换、位运算、ASCII/Unicode 等编码）
  6. 计算机基础（硬件、操作系统、网络、计算机史与人物）
  7. 阅读程序（程序阅读类专项分类）
  8. 竞赛常识与赛制（历年真题、赛制规则、各类竞赛常识）
- F1.3 **难度筛选**（P1）：入门 / 提高 / 挑战 三档；P0 题目数据可不填难度，P1 补全。
- F1.4 **题型筛选**（P0）：单选题 / 多选题 / 判断题 / 阅读程序题。
- F1.5 **题号/ID 与题目列表**：支持分页与题目总数展示。
- F1.6 **搜索**（P1）：按题干关键词模糊搜索。

### F2 练习模式（P0）
- F2.1 **四种题型全部支持**：
  - 单选题：4 个选项，唯一答案。
  - 多选题：4~5 个选项，1 个以上正确答案，**全对才得分**。
  - 判断题：正确 / 错误二选一。
  - 阅读程序题：给出一段 C/C++ 代码（代码块渲染），附带 1~N 道小题（小题可为单选/判断）。
- F2.2 **练习入口**：从题库列表按筛选条件（竞赛类型 + 知识点 + 题型）进入练习；可整页连续刷题（一题一页或列表内逐题作答，交互细节由 UI/前端定，原则是**做完立即判分**）。
- F2.3 **即时判分**：提交答案立即显示对/错、得分与正确答案。
- F2.4 **即时解析**：每题展示解析（思路 + 知识点标签 + 所属竞赛类型标签）。
- F2.5 **自动进错题本**：答错题目自动记录到错题本（含用户作答）。
- F2.6 **练习进度**（P1）：本次练习会话已答/总数、正确率实时显示。

### F3 模拟考试（P0）
- F3.1 **整卷模式**：按竞赛类型选择模拟卷（真题卷/组卷），一套卷为完整试卷（各竞赛类型均有对应模拟卷入口）。
- F3.2 **限时**：整卷倒计时（各竞赛卷时长可配置，如 CSP-J 初赛 120 分钟、蓝桥杯选拔 90 分钟等）；时间到**自动交卷**。
- F3.3 **考试中纪律**：考试期间不显示答案、不显示解析、不显示对错；支持题号导航（答题卡）与标记未答/已答。
- F3.4 **交卷**：手动交卷（二次确认）与到时自动交卷；未答题按错误处理（或按 0 分处理，规则在卷面配置）。
- F3.5 **成绩报告**：交卷后统一出分——总分、得分率、各题型/分类得分、逐题对错与解析（考后可看）。
- F3.6 **错题沉淀**：模拟考错题同样进入错题本。
- F3.7 **历史成绩**（P1）：模拟考成绩历史列表（可回看本次报告）。
- F3.8 **防刷新作弊**（P1）：考试中刷新/离开提示确认，恢复会话不丢已答（服务端保存进度）。

### F4 错题本（P0）
- F4.1 **错题列表**：按时间倒序，显示题目、错选答案、正确思路摘要。
- F4.2 **分类/题型筛选**（P1）：按知识点分类、竞赛类型、题型筛选错题。
- F4.3 **错题重练**：一键进入重练模式（只含错题）；重练答对后进入"待确认"状态。
- F4.4 **移出错题本**：连续 N 次（默认 2 次，可配置）重练答对后自动移出，或手动移除。
- F4.5 **错题统计**（P1）：各分类错误次数 Top 排行。

### F5 学习统计（P0）
- F5.1 **总体概览**：总刷题数、总正确率、总练习时长、累计模拟考次数。
- F5.2 **分类正确率**：按 8 个知识点分类展示正确率（条形图/占比）。
- F5.3 **题型正确率**：按 4 种题型展示正确率。
- F5.4 **赛事维度统计**（P1）：按竞赛类型的刷题量与正确率（为多赛事选手服务）。
- F5.5 **趋势**（P1）：近 7/30 天刷题量与正确率曲线。
- F5.6 **导出**（P2）：统计报表导出。

### F6 数据与内容（P0，支撑性）
- F6.1 **种子题库**：MVP 至少 60~100 道覆盖全部 8 类知识点 + 4 种题型 + 至少 3 个竞赛类型（蓝桥杯 / CSP-J·CSP-S / NOIP·省市校级）的题目（含解析），供开发联调与首版可用。
- F6.2 **题目字段**（供建表参考，详见 §7）：题干、选项、答案、解析、题型、知识点分类、竞赛类型（通用可扩展）、难度、来源/年份（真题标注）。
- F6.3 **竞赛类型配置**（P0，数据层）：竞赛类型以配置数据（字典/表）维护，新增类型动态出现在筛选与模拟卷入口，无需改代码。
- F6.4 **内容管理**（P2）：后台管理界面录入/编辑题目；MVP 用种子数据文件或管理接口即可。

## 4. 核心用户流程

### 4.1 注册登录流程
```
访客 → 首页/题库浏览（可匿名）→ 点击"开始练习/模拟考/错题本" → 未登录则跳转登录页
→ 登录成功 → 回到原目标页（或重定向到个人中心）→ 开始使用
```

### 4.2 分类刷题流程（主流程）
```
题库首页 → 选择竞赛类型（蓝桥杯/CSP-J/S/NOIP/省市校级/其他…，可多选）+ 知识点分类（+ 题型/难度筛选）
→ 看到题目列表 → 点击"开始练习" → 逐题作答 → 提交 → 立即显示判分 + 解析（错题自动入错题本）
→ 继续下一题 / 结束本次练习 → 本次会话小结（答对题数、正确率）→ 可去错题本或统计页
```

### 4.3 模拟考试流程
```
模拟考入口 → 选择竞赛类型下的模拟卷 → 确认考试规则（时长/题量）→ 进入考试页
→ 限时作答（题号导航，可标记未答）→ 手动交卷或到时自动交卷 → 成绩报告页
（总分/得分率/分类得分/逐题解析）→ 错题沉淀到错题本 → 可回看历史成绩（P1）
```

### 4.4 错题复习闭环流程
```
错题本 → 查看错题列表（可按分类/竞赛类型筛选）→ 进入重练模式 → 作答 → 判分与解析
→ 连续 2 次答对 → 自动移出错题本 → 错题减少，统计页薄弱分类正确率回升
```

### 4.5 统计查看流程
```
个人中心/导航 → 学习统计页 → 查看总体概览 + 分类/题型正确率
→ 发现薄弱分类 → 点击该分类跳转题库（自动带分类筛选）→ 针对性练习 → 回到统计看变化
```

## 6. 验收标准（每项功能的完成定义 DoD）

### 全局标准
- [ ] 全站可在现代浏览器（Chrome/Edge 最近两个大版本）正常运行，无控制台报错。
- [ ] 关键操作（登录、答题、交卷）均有加载态与错误提示。
- [ ] 刷新页面后登录态保持；未登录访问受保护页面会跳转登录页并在登录后回跳。

### F0 用户系统
- [ ] 用户名重复注册给出明确提示且不创建账号。
- [ ] 密码至少 6 位；登录失败提示"用户名或密码错误"（不区分具体错误）。
- [ ] 退出登录后，受保护页面不可再访问。

### F1 题库浏览与分类
- [ ] 竞赛类型（蓝桥杯 / CSP-J / CSP-S / NOIP / 省市校级 / 其他·综合 等，多选）、8 类知识点、4 种题型筛选可独立使用且可组合。
- [ ] **竞赛类型可扩展性验证**：通过数据配置新增一个竞赛类型（如 NOI 笔试）后，筛选选项与模拟卷入口自动出现该类型，无需改代码。
- [ ] 筛选结果与题目列表、总数一致；分页可用。
- [ ] 种子题库覆盖全部 8 类知识点 × 4 种题型 × 至少 3 个竞赛类型（P1 难度筛选可用时，题目含难度字段）。

### F2 练习模式
- [ ] 四类题型均可作答与提交；单选/判断提交后正确判分，多选**全对才得分**，阅读程序题各小题独立判分。
- [ ] 提交后 1 秒内显示对错、正确答案与解析。
- [ ] 答错题目写入错题本，再次打开错题本可见该题与用户作答。

### F3 模拟考试
- [ ] 选择模拟卷（各竞赛类型均有卷）后进入限时考试；倒计时准确，时间归零自动交卷。
- [ ] 考试期间任何页面均不显示答案/解析/对错。
- [ ] 题号导航可跳转任意题；答题卡正确标记已答/未答。
- [ ] 手动交卷有二次确认；交卷后展示成绩报告（总分、得分率、分类得分、逐题解析）。
- [ ] 模拟考错题进入错题本。

### F4 错题本
- [ ] 练习与模拟考产生的错题均自动出现在错题本（含错选答案）。
- [ ] 错题重练可作答并判分；连续 2 次答对后自动移出，手动移除可用。

### F5 学习统计
- [ ] 总刷题数、总正确率、累计模拟考次数随答题实时更新且数值与服务端记录一致。
- [ ] 分类正确率、题型正确率图表正确反映题库答题数据（含错题本重练计入）。

### F6 数据与内容
- [ ] 种子题库 ≥ 60 道，覆盖 ≥ 3 个竞赛类型，含解析，导入脚本可重复执行不产生重复数据。
- [ ] 竞赛类型为配置数据驱动：新增类型不修改代码即可生效（见 F1 扩展性验证）。

## 7. 数据字段要点（供架构师建表参考，非最终设计）

- **竞赛类型表（新增，通用可扩展）**：`id`、`code`（如 `lanqiao`/`csp-j`/`csp-s`/`noip`/`noi`/`province-city-school`/`other`）、`name`（展示名，如"蓝桥杯"）、`sort_order`、`enabled`。新增竞赛类型只需插一条数据。
- **题目表**：`id`、`stem`（题干，支持代码块/Markdown）、`type`（single/multiple/judge/reading）、`options`（JSON）、`answer`（JSON，多选为数组、阅读程序为小题答案数组）、`analysis`（解析）、`knowledge_category`（8 类之一）、`competition_types`（**数组，关联竞赛类型表，可多选**）、`difficulty`（P1）、`source`（来源/年份）、`created_at`。
- **阅读程序题**：题干含代码块，子小题以 JSON 数组内嵌（`sub_questions`）。
- **答题记录表**：`user_id`、`question_id`、`user_answer`、`is_correct`、`source`（practice/exam）、`exam_id`（可空）、`created_at`。
- **错题本表**：`user_id`、`question_id`、`wrong_count`、`review_correct_streak`（连续答对次数）、`status`（active/removed）。
- **考试表**：`id`、`title`、`competition_type`（关联竞赛类型表）、`duration_minutes`、`question_ids`（JSON 组卷）、`is_auto_generated`。
- **考试成绩表**：`user_id`、`exam_id`、`score`、`total`、`answers`（JSON）、`submitted_at`。

## 8. 非功能需求（要点）

1. **性能**：题库列表接口分页返回 ≤ 50 条/页；题目详情首屏加载 < 1s（本地环境）。
2. **数据安全**：密码哈希存储（bcrypt 等），JWT 过期与刷新策略由后端定。
3. **兼容性**：桌面浏览器优先；移动端可基本使用（响应式，P1）。
4. **可维护性**：题目数据与代码分离（种子数据文件/JSON），便于后续扩充题库；**竞赛类型、知识点分类等维度数据配置化**，支持无代码扩展。
5. **部署**：本地开发 + 可部署到单机服务器；前后端分离架构（详见架构设计文档）。
