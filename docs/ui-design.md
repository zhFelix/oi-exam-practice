## 1. 设计定位与原则

### 1.1 设计定位

面向备战**各类信息学竞赛笔试**的中学生（CSP-J/S、NOIP、蓝桥杯、省市校级赛事等），产品气质应是**「赛博刷题舱」**：干净、专注、有科技感、有竞技感——像程序员写代码一样刷题，像考场一样严肃，但绝不冰冷。

关键词：**深色科技风 · 信息层级清晰 · 即时反馈 · 竞技数据感**。

### 1.2 设计原则

| # | 原则 | 落地要求 |
| --- | --- | --- |
| 1 | **专注优先** | 答题页无多余装饰，题目区是绝对主角；导航在答题/考试时收起为最小形态 |
| 2 | **即时反馈** | 提交判分 1 秒内呈现对/错视觉反馈 + 解析（F2.3/F2.4 验收）；所有按钮有按压/悬停状态 |
| 3 | **色彩语义化** | 颜色只承载含义：蓝=主操作/链接、绿=正确、红=错误、橙=警告/未答、灰=禁用/次要 |
| 4 | **数据可视化** | 统计页图表直观展示薄弱分类，能"一眼看出哪里弱"（F5） |
| 5 | **一致性与复用** | 全站共用组件库（按钮/卡片/选项/答题卡/弹窗），不出现同一元素两种样式 |
| 6 | **考试真实感** | 模拟考页顶部固定倒计时条 + 答题卡，接近真实机考界面（F3.3） |

## 2. 视觉规范

### 2.1 配色方案（信息学竞赛·科技深色风）

采用 **深色主题为默认**（代码/终端气质），浅色模式列为 P1 可选（CSS 变量已预留）。

#### 主色板

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--bg-page` | `#0B1220` | 页面背景（深海蓝黑） |
| `--bg-surface` | `#111A2E` | 卡片/面板背景 |
| `--bg-surface-2` | `#182442` | 次级面板/悬浮层 |
| `--bg-code` | `#0D1526` | 代码块背景 |
| `--border` | `#24304D` | 卡片边框/分割线 |
| `--primary` | `#2E6BFF` | 主操作色（科技蓝） |
| `--primary-hover` | `#4D84FF` | 主操作悬停 |
| `--primary-soft` | `rgba(46,107,255,.14)` | 主色浅底（选中态/标签底） |
| `--accent` | `#00D4FF` | 强调色（青蓝，计时器/高亮） |
| `--success` | `#22C55E` | 正确 / 答对 |
| `--danger` | `#F43F5E` | 错误 / 答错 |
| `--warning` | `#F59E0B` | 警告 / 未答 / 待确认 |
| `--text-main` | `#E8EDF7` | 主文字 |
| `--text-secondary` | `#93A2C3` | 次要文字 |
| `--text-muted` | `#5A6A8C` | 弱化文字/占位 |
| `--link` | `#7CB8FF` | 链接/可点击文字 |

#### 语义用法速查

| 状态 | 主色 | 辅助元素 |
| --- | --- | --- |
| 答对 | `--success` 绿 | 选项右缘绿边框 + 左侧绿竖条 + ✓ 图标 |
| 答错 | `--danger` 红 | 选项右缘红边框 + 左侧红竖条 + ✗ 图标；正确项绿框提示 |
| 未答（考试） | `--warning` 橙 | 答题卡题号橙色空心 |
| 已答（考试） | `--primary` 蓝 | 答题卡题号蓝色实心 |
| 当前题（考试） | `--accent` 青 | 答题卡题号青色描边 + 放大 |
| 交卷按钮 | `--warning` 橙 | 二次确认弹窗 |

> 配色校验：绿/红对比同时配合 **图标 + 文字**（"回答正确"/"回答错误"）双重编码，不依赖色觉。

### 2.2 字体与排版

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-sans` | `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif` | 全站正文/标题 |
| `--font-mono` | `"JetBrains Mono", "Consolas", "Courier New", monospace` | 代码块、计时器、题号、数字统计 |
| 基础字号 | 14px（正文） | 移动端 13px（P1） |
| 标题层级 | H1 24/28 · H2 18/20 · H3 16 · 正文 14 · 辅助 12 | 行高 1.6（正文）/ 1.4（标题） |

- 英文/数字/分数一律用等宽字体（代码块、倒计时、正确率百分比），增强"数据感"；
- 代码块（阅读程序题）用 `--font-mono` 13.5px，行号可选（P1），语法不高亮（保留原文，避免误导）。

### 2.3 间距 / 圆角 / 阴影

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32px | 统一 4px 网格 |
| 卡片内边距 | 16~24px | 内容卡片 |
| `--radius-sm` | 6px | 输入框/小按钮 |
| `--radius-md` | 10px | 卡片/按钮 |
| `--radius-lg` | 16px | 弹窗/大卡片 |
| 阴影 | `0 4px 16px rgba(0,0,0,.35)` | 卡片浮起态/弹窗 |

### 2.4 断点（响应式，P1 完善）

| 断点 | 宽度 | 布局 |
| --- | --- | --- |
| 桌面（主目标） | ≥ 1024px | 完整导航 + 侧栏筛选（题库页）+ 答题区居中 720px |
| 平板 | 768~1023px | 筛选收为抽屉 |
| 移动（P1） | < 768px | 单列流式；答题卡底部抽屉 |

## 3. 全局组件规范（前端组件清单）

| 组件 | 文件 | 要点 |
| --- | --- | --- |
| 顶部导航 `navbar` | `js/components/navbar.js` | 见 §4.1 |
| 题目卡片 `question-card` | `js/components/question-card.js` | 题干（Markdown+代码块）→ 选项组 → 答题区 → （判分后）反馈区。**三种模式**：`view`（浏览）、`practice`（练习即时判分）、`exam`（考试无反馈） |
| 答题卡 `answer-sheet` | `js/components/answer-sheet.js` | 题号网格；状态色见 §2.1；点击跳题；考试时固定右侧/底部 |
| 倒计时 `timer` | `js/components/timer.js` | 等宽数字 `MM:SS`；最后 5 分钟变橙色、最后 1 分钟红色脉冲 |
| 弹窗 `modal` | `js/components/modal.js` | 二次确认（交卷/退出练习）、提示 |
| Toast `toast` | `js/components/toast.js` | 顶部滑入，3s 自动消失；成功绿/错误红/提示蓝 |
| 筛选器 `filter-bar` | 题库页内联 | 竞赛类型 Chip 组（**由 `GET /api/meta/competition-types` 动态渲染，可扩展任意赛事**）+ 分类 Chip + 题型 Chip + 难度（P1） |
| 分页器 `pagination` | 题库页内联 | `‹ 1 2 3 … ›`，显示总数 |
| 图表（统计页） | 页内 Canvas/CSS | 横向条形图（分类/题型正确率），P1 折线趋势（SVG） |

### 3.1 按钮规范

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮（蓝） | 实心 `--primary`，白字，radius-md，高度 40px | 开始练习、提交、登录、交卷（考试页交卷例外为橙色警告） |
| 次按钮 | 透明底 + 1px `--border` + 主文字 | 取消、返回、预览 |
| 文字按钮 | 无底，`--link` 色 | 页面内跳转（看解析、去错题本） |
| 危险按钮 | 实心 `--danger` | 手动移出错题本（带二次确认） |
| 禁用态 | 40% 透明度，禁止光标 | 未登录答题、已交卷 |

### 3.2 选项组件（核心交互）

- 单选：圆形 radio 风格选项块，整行可点击（点选项文字即选中）；
- 多选：方形 checkbox 风格，选项前标注 `□/☑`，选中高亮蓝边；
- 判断题：两个大按钮"正确 T / 错误 F"；
- **判分后反馈**（练习/重练）：正确选项绿框 + ✓，错选项红框 + ✗，正确项同时绿框提示；选项块下方展开解析区（`--primary-soft` 底 + 左侧蓝竖条）；
- 考试模式：选项无对错反馈，仅选中态。

## 4. 全局布局

### 4.1 页面骨架（桌面）

```
┌────────────────────────────────────────────────────────────┐
│ [logo ◈ OI练习] 题库 模拟考 错题本 统计 │ 登录/注册 │ 用户名▾ │   ← 顶部导航 64px 深色
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    内容区（max-width 1200px，居中）            │
│                                                            │
├────────────────────────────────────────────────────────────┤
│  © 2024 OI练习 · 备考各类信息学竞赛笔试 · 题库持续扩充       │
└────────────────────────────────────────────────────────────┘
```

- 顶部导航：深色吸顶（`--bg-page` + 底部 1px `--border`）；logo 用「◈」几何徽标 + "OI练习"；未登录显示"登录 / 注册"，已登录显示用户名下拉（个人中心 / 退出登录）；
- 页面最大宽度 1200px，答题/考试页内容区收窄至 720px 保证专注；
- 登录/注册/考试页**不显示页脚**（考试页连导航也隐藏，防止误点离开）。

## 5. 页面线框（Wireframes）

> 线框用 `+` `-` `|` 绘制，标注关键交互（❯ 表示交互动作）。非像素稿，前端按 §2/§3 规范还原。

### P1 首页 / 题库浏览页 `#/`

```
┌───────────────────────────────────────────────────────────────┐
│ 题库                                                           │
│ [CSP-J|CSP-S|NOIP|蓝桥杯|省赛|市赛|校赛|其他|全部]                 │
│   ← 竞赛类型 Chip 组，数据驱动动态渲染（F1.1，见 §5.1.3 扩展机制）    │
│                                                               │
│ 知识点： [C++语言基础] [数据结构] [算法] [数学] [计算机基础]       │
│          [阅读程序] [NOI相关知识]          ← Chip 多选（F1.2）     │
│ 题型：   [单选题] [多选题] [判断题] [阅读程序题]  ← Chip（F1.4）    │
│ 难度：   [入门] [提高] [挑战]（P1，F1.3）    [搜索框 🔍]（P1）      │
│ ───────────────────────────────────────────────────────────── │
│ 共 86 题                        [开始练习 ▶]（按当前筛选）        │
│ ┌───────────────────────────────────────────────────────────┐ │
│ │ q0001  [单选] [C++语言基础] [CSP-J] · 2023真题               │ │
│ │ 以下哪个是合法的 C++ 变量名？                                 │ │
│ │                        [练习]                              │ │
│ ├───────────────────────────────────────────────────────────┤ │
│ │ q0002  [多选] [数据结构] ...                                │ │
│ └───────────────────────────────────────────────────────────┘ │
│    ‹ 1 2 3 4 ›   共 86 题（F1.5 分页，20 条/页）                 │
└───────────────────────────────────────────────────────────────┘
```

交互要点：
- 筛选条件可组合，任一变化即重新请求列表（防抖 300ms）；筛选结果与总数一致（DoD F1）；
- **竞赛类型标签由元数据接口动态渲染**：前端启动时拉取 `GET /api/meta/competition-types` 生成 Chip 组，新增赛事（如蓝桥杯、省赛）无需发版即可出现；标签过多时折叠为「更多 ▾」弹出层（架构 §5.1.3）；
- 未登录：列表与题目可见，点"开始练习"→ Toast"请先登录"→ 跳登录页并回跳（F0.4）；
- 列表项点击 → P12 题目详情（P1）；「练习」按钮 → 进入 P2 且携带当前筛选（F2.2）。

```

│ ┌───────────────────────────────────────────────────────────┐ │
│ │ 第 3 题/共 10 题    [单选题] 难度 ●○○   来源：CSP-J 2022      │ │
│ │                                                           │ │
│ │ 题号 q0007                                                │ │
│ │ 下列排序算法中，平均时间复杂度为 O(n log n) 的是？              │ │
│ │                                                           │ │
│ │ ( ) A. 冒泡排序            ( ) B. 插入排序                  │ │
│ │ ( ) C. 快速排序            ( ) D. 选择排序                  │ │
│ │                                                           │ │
│ │              [提交答案]            ❯ 提交后：               │ │
│ │                                          ✓ 回答正确!         │ │
│ │                                          ┌ 解析区 ┐          │ │
│ │                                          │ 快排平均 O(nlogn) │ │
│ │                                          │ 知识点: 算法      │ │
│ │                                          └────────┘          │ │
│ │              [下一题 ▶]                                     │ │
│ └───────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

交互要点：
- **即时判分**（F2.3）：提交 → 1s 内选项变绿/红 + Toast + 解析区展开（F2.4）；
- 答错自动入错题本：判分后 Toast 附"已加入错题本"徽标（F2.5）；
- 已提交的题不可改答；「下一题」推进；最后一题变「完成练习」→ 本次会话小结弹窗（答对 X 题 · 正确率 Y%）→ 可选"去错题本 / 去统计 / 返回题库"（F2.6 P1 进度条，本次会话正确率 P0 小结）；
- 阅读程序题：题干上方渲染代码块（等宽、可横向滚动），下方逐子题作答，**整题一次提交**，判分按子题展开对错（DoD F2 子题独立判分）。

### P5 成绩报告页 `#/exam/:id/result`

## 6. 关键交互与状态设计

### 6.1 判分反馈状态机（练习/重练）

```
未作答 ──提交──► 判分中(按钮 loading "判分中…") ──响应──►
   已判分（正确: 绿框+✓+解析 / 错误: 红框+✗+绿框提示+解析）
   ──下一题──► 下一题未作答 … ──完成──► 会话小结弹窗
```

### 6.2 考试状态机

```
规则确认 ──开始──► 考试中(倒计时+答题卡+禁答案) ──手动交卷(二次确认)──►
                                       └──倒计时归零 自动交卷──►
   成绩报告(总分/分类/逐题) ──► 错题入本 Toast ──► [去错题本|再考一次]
```

### 6.3 空状态与加载状态

| 场景 | 呈现 |
| --- | --- |
| 题库筛选无结果 | 居中插画占位 + "没有符合条件的题目，试试调整筛选条件" + [清除筛选] |
| 错题本为空 | "太棒了，目前没有错题 🎉" + [去刷题] |
| 统计页无数据 | "答题后这里将展示你的学习数据" |
| 列表/判分加载中 | 骨架屏（卡片灰块微闪）或按钮 loading 态 |
| 网络/服务错误 | 居中错误插画 + [重试]；Toast 显示错误信息（DoD 全局） |

### 6.4 动效规范

| 元素 | 动效 | 时长 |
| --- | --- | --- |
| 选项选中 | 边框+背景 1 帧过渡 | 120ms |
| 判分反馈 | 选项变色 + 解析区淡入下滑 | 200ms |
| Toast | 顶部滑入/滑出 | 300ms / 停留 3s |
| 答题卡题号状态变化 | 背景色过渡 | 150ms |
| 弹窗 | 淡入 + 缩放 | 200ms |
| 页面切换 | 内容区淡入 | 150ms（无转场动画，保持轻快） |
| 倒计时最后 1 分钟 | 红色脉冲（CSS keyframes） | 1s 循环 |

- 遵循 `prefers-reduced-motion`：用户偏好减弱动效时全部降为无/极简（可访问性）。

### 6.5 无障碍要点

- 所有可交互元素有键盘焦点态（2px `--accent` 外框）；
- 选项、按钮、题号导航均可 Tab 聚焦 + Enter 操作；
- 判分对错用"图标 + 文字"双重编码（不依赖颜色）；
- 表单控件有 label；弹窗用 role=dialog + aria-labelledby；
- 对比度：正文 `--text-main` 在 `--bg-page` 上 ≥ 7:1，次要文字 ≥ 4.5:1。

## 7. 前端实现落地要点（对接架构文档）

1. **CSS 变量集中管理**：`css/base.css` 定义 §2 全部令牌；页面只引用变量，禁止硬编码色值；
2. **组件复用**：`question-card.js` 的 `practice` 模式同时服务 P2/P7；`exam` 模式服务 P4，保证一致性（原则 5）；
3. **与 API 对齐**：字段 camelCase（架构 §6）；列表/判分/统计接口的响应结构已固定，页面模块按契约取数；
4. **路由守卫**：`router.js` 统一处理需登录路由与 redirect 回跳（§4.2）；
5. **考试页**独立 CSS（无导航、禁滚动穿透、答题卡固定），由 `exam-taking.js` 独占渲染，防止误入其他页面（beforeunload 提示）。
